Finsight — CS50 Final Project

Project Overview

Finsight is a stock research web application designed to help users view stock market information and technical indicators in one place.

Demonstration Video

YouTube: https://www.youtube.com/watch?v=jyjfECbQ0Xk

Features

Create and view ticker views.

View stock prices and market information.

Analyse technical indicators such as RSI and MACD.

Create an account and log in.

Receive browser notifications and hourly stock reports when configured.

Technologies Used

Python

Flask

SQLite

HTML

CSS

JavaScript

Yahoo Finance data through yfinance

How to Run

Install Python 3.12 or another compatible Python version.

Install the required packages:

py -m pip install -r requirements.txt

Run the application:

py app.py

Open the local address displayed in the terminal in your web browser.
